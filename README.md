# 🌳 Conversational Data Storytelling for Monumental Trees  
### An Interactive Web Platform with LLM-Based Chatbots

This repository contains the **frontend web application developed as part of my Master’s Thesis**, focused on the design, development, and evaluation of an **interactive system for the valorization of monumental trees**.

The project explores how **modern web technologies, data storytelling principles, and Large Language Model (LLM)–based conversational systems** can be combined to make complex environmental, cultural, and territorial data more **accessible, engaging, and meaningful** for a broad audience.

---

## 📌 Project Highlights

### 🔍 Problem Statement
The increasing availability of digital data, together with recent advances in artificial intelligence, has profoundly transformed how information is produced, communicated, and consumed.  
Despite this evolution, **environmental and natural heritage data**, such as those related to monumental trees, are often:

✔ Fragmented across heterogeneous sources  
✔ Difficult to access for non-specialist users  
✔ Technically complex and poorly contextualized  
✔ Presented through static and non-interactive platforms  

This gap between the **intrinsic value of the heritage** and its **effective understanding** motivates the need for systems capable not only of visualizing data, but of **transforming data into knowledge**.

---

## 🛠️ Our Approach

The project proposes an **interactive, user-centered platform** that integrates:

- **Modern web development** for flexible and scalable interfaces  
- **Data storytelling** to structure information into coherent narratives  
- **Conversational AI** to support natural, adaptive, and personalized interaction  

At the core of the system is a set of **LLM-based chatbots implemented through a Retrieval-Augmented Generation (RAG) architecture**, enabling users to explore data through dialogue rather than rigid navigation paths.

The approach explicitly investigates how **different communication strategies and interaction modalities** influence user experience and information effectiveness.

---

## ⚙️ System Architecture

The application is based on a **modular and scalable architecture**, designed to ensure flexibility, adaptability, and clear separation of concerns.

### 🌐 Backend and Frontend Platform
- Interactive web application for data exploration  
- Narrative and informational sections dedicated to monumental trees  
- User preference and context management  
- Designed for accessibility and non-expert audiences  

### 🤖 Conversational Layer (RAG)
- LLM-based chatbots with differentiated interaction styles  
- Context-aware dialogue management  
- Grounded generation via document and data retrieval  
- Personalization based on user interaction patterns
- Microservice Architecture: https://huggingface.co/spaces/benny2199/rag-microservice/tree/main

---

## 🚀 Interaction Modalities

The platform includes **three distinct modes**, designed to compare different communicative strategies:

- 📄 **Informative Mode**  
  Structured, static presentation of content with high pragmatic clarity.

- 📖 **Narrative Chatbot**  
  Immersive and relational conversational style, focused on engagement and emotional involvement.

- 🔬 **Scientific Chatbot**  
  Balanced conversational approach combining informational rigor with user engagement.

---

## 📊 Evaluation & Key Results

The system was evaluated through **user testing**, using metrics derived from the **User Experience Questionnaire (UEQ)**.

### 🔑 Key Findings

✔ Informative mode showed strong pragmatic effectiveness but lower engagement  
✔ Narrative chatbot achieved the highest scores in hedonic dimensions  
✔ Scientific chatbot balanced rigor and engagement effectively  
✔ Conversational approaches significantly improve accessibility of complex content  
✔ Different interaction styles address different cognitive needs and usage patterns  

These results confirm the **central role of conversational systems** in the communication of complex scientific and environmental information.
